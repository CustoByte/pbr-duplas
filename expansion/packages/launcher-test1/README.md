# PBR Duplas — launcher Windows 1.0

Execute uma última vez o mesmo CMD. Ele instala o aplicativo e cria o atalho
PBR Duplas na Área de Trabalho e no menu Iniciar. Depois, use apenas o atalho.

Verifica o GitHub, aplica atualizações e inicia o jogo no Dolphin, sem console.
Preserva os caminhos e a RVZ já instalada. Atualizações só do launcher não
reconstroem o jogo. Modelos já instalados são recuperados e guardados localmente;
nenhum seletor de ZIP é aberto durante as atualizações.

Verificações Windows: interface WPF renderizada, estado legado preservado,
workers ocultos, integridade dos pacotes e recuperação automática de gráficos.
A versão do jogo continua v0.14.0-charizard-y-test.2; nenhum patch do jogo mudou.
