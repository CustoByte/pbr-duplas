# Mega Lucario — teste 3 (Windows)

Use o mesmo **INICIAR-TESTE-WINDOWS.cmd** e inicie a imagem atualizada pelo
começo normal, sem carregar um estado rápido antigo. Não precisa baixar outro
instalador. O cache gráfico existente pode ser reutilizado.

Corrige o nome vazio, permite exibir MEGA LUCARIO completo em Strings dinâmicas
e corrige a leitura de Pokémon com checksum adiado durante a batalha. Mantém
moveset, atributos, Adaptability, ausência de item, Snivy e Lucario normal.
As 433 correções de tradução anteriores continuam incluídas.

Os testes nativos passaram, inclusive usando as tabelas do estado enviado.
**O aviso Invalid read e o anúncio visual do golpe ainda precisam de confirmação
em batalha no Dolphin Windows. Esta versão é experimental.**
